# Repository Learnings

- A scheduled or manually dispatched `latest` release must build, check out, and tag the same immutable commit SHA. Deleting only the GitHub release leaves the movable `latest` tag pointing at its previous commit.
- Animated-image support is not proven by decoder or demuxer listings alone. Generate two-frame GIF and WebP fixtures, count decoded frames from files, and repeat decoding through non-seekable stdin streams on every supported platform.
- Pass multi-word compiler flags to CMake through `CFLAGS`; expanding them as one unquoted command-line variable makes flags such as `-O2` become unknown CMake arguments.

- A shallow unpatched checkout and an index-applied patch retain the same Git HEAD. Use a patch/tree-identifying FFmpeg `--extra-version` suffix plus a verified full source tree and binary SHA256; the upstream version string alone cannot distinguish the candidate. Verified against FFmpeg's version script and the actual patch application.
- Run `gh` with explicit `-R EthanSK/static-ffmpeg-binaries`: this clone's `upstream` remote is marked as the resolved GitHub base, so an implicit repository could target shaka-project.
- Check copied packet timestamps with `-copyts -copypriorss 1` near a stream-time-base boundary. Accurate decode trimming can hide a rounded-forward seek. The synthetic PCM regression rejects a deliberately wrong target and verifies the first packet is at or before the requested timestamp.
- macOS `/bin/bash` 3.2 treats an empty array expansion as unbound under `set -u`. Keep optional argv in an always-populated argument array rather than expanding a separate empty optional array. Verified with the native shell before fixing the seek-check wrapper.
- Multi-audio seek fixtures need distinct sample rates/time bases. Equal-rate tracks can miss using the first track's clock for a selected later track; verify both rates and compare the selected PCM at its native rate, without a resampler hiding the timestamp error.
- The pinned upstream upgrade discards AAC encoder padding at the declared program end. On the six-second 48 kHz synthetic MP4, old `20b009e` emits 768 samples after 6s, while both `86444dd` control and patched builds return zero. The upstream `libavformat/demux.c` change uses codec frame size when computing discarded samples. Keep this exact expected upgrade delta explicit, while retaining candidate/control equality and failing other unreviewed count changes.
- Short AAC seek cases do not prove sample-exact equivalence at long Matroska offsets. The released rc2 macOS candidate sought a ten-minute 48 kHz AAC MKV at 250s and produced 48,008 samples for `-t 1`, beginning eight samples before linear `atrim` (48,000 samples); long PCM MOV/MKV and AAC MP4 were byte-exact. Verify content alignment as well as counts, and retain application workarounds until real commands qualify. This is a selected-seek limitation; candidate/control default-output equality still passed.
